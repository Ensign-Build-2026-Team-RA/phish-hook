## Recommended PowerPoint use

- Set slides to **Widescreen (16:9)**.
- Use the Phil title background for the opening, problem statement, or closing slide.
- Use the clean background for content, architecture, demo, and results slides.
- Keep body text in the darker center and left areas.
- Use the transparent Phil cutout sparingly on section breaks or callout slides.
- Treat Phil as the villain: he represents the phisher setting the bait.
- Use aqua for highlights, gold for warnings, off-white for headings, and navy for foundations.
- Prefer **Inter**, **Aptos**, or **Arial**. Use a heavy weight for titles and a regular weight for body copy.
- Maintain at least 0.5 inches of safe space around text and logos.
